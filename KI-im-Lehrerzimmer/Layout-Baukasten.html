Layout-Baukasten

Ein einheitliches Layout für alle Blätter – Lernsituation, Informationsblatt, Quiz, Lösung – in drei Schritten. Läuft ohne Internet, einfach herunterladen und im Browser öffnen.

1 · Stil wählen

Ein Klick genügt – in der Vorschau sehen Sie sofort das Ergebnis. Anpassen können Sie im nächsten Schritt.

2 · Kleinigkeiten anpassen

Alles ist schon passend eingestellt. Ändern Sie nur, was Ihnen nicht gefällt.

3 · Mitnehmen

Fertig. So geben Sie Ihr Layout an Claude weiter.
